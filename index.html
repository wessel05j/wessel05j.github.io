02 / The tool behind the work

Open source · Used in my workflow

VerbaCut.

Long videos in.
Promising moments out.

The project I’ve spent the most time on. VerbaCut transcribes video locally, uses a local language model to find promising moments, and exports clips for review.

I built it into my BeyondComfort workflow. Checkpoints, resumable processing, and unattended runs help it handle the long jobs, too.

04 / An experiment in a whole workflow

Open source · V1 prototype

Recruitment
Pipeline OS.

From a rough brief
to a shortlist worth reviewing.

I wanted to explore how much of a research workflow could be connected. This pipeline turns a hiring brief into GitHub searches, AI-assisted candidate reviews, a ranked shortlist, and a structured PDF report.

The first version focuses on technical roles with public GitHub evidence. The output is there for a person to review.

  • Python
  • OpenAI API
  • GitHub API
  • ReportLab
